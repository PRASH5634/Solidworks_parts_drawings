# Mechanical Design | SolidWorks Portfolio

**Selected 3D CAD modeling studies · TH Deggendorf (THD)**

A collection of nine mechanical design and geometric modeling studies made in SolidWorks. The models explore practical mounting interfaces, flanged housings, circular features, profile transitions and helical geometry. The focus is on clear design communication and feature-based CAD work.

## Selected CAD studies

| Component | Design features demonstrated |
| --- | --- |
| **Cantilever Bracket** | Reinforced cantilever geometry, curved ribs and mounting interfaces |
| **Loft** | Tapered loft profiles transitioning around a circular central section |
| **Multi-Port Valve** | A tapered housing with multiple angled cylindrical ports and a mounting flange |
| **Pencil** | A slender, faceted object with a pointed tip and longitudinal features |
| **Pump Housing** | Connected cylindrical features, circular flanges and a mounting-hole pattern |
| **Shaft Support Bracket** | Raised cylindrical support geometry and a broader mounting base |
| **Spoked Wheel Housing** | Radial spokes, central hub and perforated mounting lugs |
| **Spring** | A tapered, multi-turn helical spring form |
| **Wheel** | A circular rim with three shaped internal radial features |

## Skills illustrated

- **SolidWorks part modeling:** extruded and revolved forms, cuts, fillets, ribs and repeated features.
- **Complex geometric forms:** lofts, helix-based sweeps and intersecting cylindrical surfaces.
- **Mechanical design thinking:** geometric support, reinforcement, flanges, fastening interfaces and concentric layout.
- **Documentation:** readable views, organized project naming and concise design explanations.

## Technical scope

These are **CAD modeling studies**, not certified manufacturing drawings. The available PDFs are model views rather than fully dimensioned drawings; performance, dimensions, materials and tolerances have not been validated from those images. The SolidWorks exports contain an educational-use notice.

The complete project gallery, including the original screenshots, paired PDF views and detailed descriptions, is being assembled for this repository.
